# 马赛克壁画工作台（Mosaic Studio）

浏览器内的马赛克壁画排块与光照预览系统：TypeScript + Vue 3 + WebGL2 自研着色器，数据全部存 IndexedDB，无后端。

## 启动

```bash
pnpm install
pnpm dev        # 开发
pnpm build      # 类型检查 + 生产构建
pnpm test:smoke # 核心逻辑冒烟测试（可复现性 / Lab 色差 / 20 万级性能）
```

首次启动自动播种：24 种材料（玻璃/金箔/石材）、3 张程序化原稿（人像、几何图案、半穹顶画）、
3 个示例项目，其中酒店大堂主墙按 10m×2m、10mm 块生成约 15 万块。

## 页面与需求对应

| 页面 | 覆盖需求 |
| --- | --- |
| 项目列表 | 按墙面管项目；平面/圆柱弧面/半穹顶，尺寸、曲率、朝向可设 |
| 原稿处理 | 图片导入；Sobel + 结构张量生成主体走向引导线（人脸/衣褶顺向） |
| 排块编辑 | 确定性自动排块；块大小/缝宽/切割随机度/倾角/顺走向强度可调；手动拖块、改色、改倾角 |
| 材料库 | 玻璃/金箔/石材分类，颜色、透明度、表面起伏、反光参数、库存 |
| 墙面预览 | WebGL2 实时光照；Fresnel 反射、金箔视角相关闪烁；自然光/射灯/烛光；死白区域红色预警 |
| 施工图 | 每平方米分格出图、块级颜色编号、浏览器打印、材料清单按颜色汇总用量与库存差 |
| 版本历史 | 每次排块留存版本，可回到任一版 |

## 关键架构决策

### 性能：20 万块单 draw call

- 块数据 24 字节/块紧凑二进制（`TILE_STRIDE`，Float32×5 + Uint32 材料索引），20 万块约 4.6MB，整存 IndexedDB
- WebGL2 实例化渲染：每实例 48 字节属性缓冲，`drawArraysInstanced` 一次提交，墙面曲率在顶点着色器内计算
- 2D 编辑器只绘制视口内的块，拾取按网格 O(1) 粗筛 + 旋转矩形包含测试

### 可复现排块

- mulberry32 PRNG + FNV-1a 参数哈希；每块的随机数由 `(seed, col, row, salt)` 独立派生（`cellRng`），
  与遍历顺序无关。同参数同种子生成结果字节级一致（冒烟测试断言）

### 颜色匹配：Lab + CIEDE2000

- sRGB→线性→XYZ(D65)→Lab，匹配用 CIEDE2000（Sharma 2005 修订版），不用 RGB 欧氏距离
- Lab 体素格（边长 16）预筛候选，再精算 ΔE；库存耗尽自动降级并计入告警；ΔE>5 提示超色域；用色超 24 种提示

### 墙面几何

平面/弧面/穹顶统一为布局坐标 `(u,v)∈[0,1]² → 3D` 的参数化映射（`src/core/wall.ts`），
排块引擎与墙型完全解耦；同模块提供射线求交用于画布拾取。

## 目录

```
src/core    领域逻辑：类型、确定性随机、Lab/CIEDE2000、流场、排块、匹配、墙面几何
src/render  WebGL2 渲染器、轨道相机、光源预设、2D 画布与施工图工具
src/data    IndexedDB 封装、仓储、种子数据
src/pages   七个页面
src/components 共享 UI（线性图标、空状态、表单、打印分格）
scripts     Node 端冒烟测试
```

## 已知边界

- 金箔不参与自动取色（避免肖像区随机闪金），需在排块编辑里手动指定
- 施工图打印走浏览器原生打印，分页尺寸由打印对话框控制
- 半穹顶按等角参数化展开，块在拱顶附近会自然收拢，与真实裁切工艺一致
